## Объявление значений и функций
- `let` - используется для объявления не только переменной, но и функции к которой можно обращаться.

**Прмиер:**
```
1. let number = 5
2. let sum x y = x + y
    let result = sum 5 10 // -> 5+10 = 15
```

## Списки (list)
- Списи имеют фиксированную длину и тип при объявлении и не являються изменяемыми.
- Списки можно разделить на первый символ и остальну часть (head, tail)

**Пример:**
```
let numbers = [1; 2; 3; 4]

let rec sum numbers =
    match numbers with
    | [] -> 0
    | head :: tail -> head + sum tail
```

```
1: 1 + sum [2; 3; 4]
2: 2 + sum [3; 4]
3: 3 + sum [4]
4: 4 + sum []
5: 0
=> 1 + (2 + (3 + (4 + 0)))
```

| Команда | Содержит |
|---|---|
| `head` | 1 |
| `tail` | 2; 3; 4 |

## Рекурсия (rec)
- **Рекурсия** - это функция которая вызывает сама себя и выполняет какое-либо дейтсвие.
- В рекурсивной функции обязательно должно быть два услвоия: 
    1. **Базовый случай** - это условие при котором рекурсия прекращается.
    2. **Рекурсивный шаг** - это условие при котором шаг продолжается и ведет к базовому случаю.

**Пример:**
```
let rec sum nums = 
    match nums with
    | 0 -> []
    | head :: tail -> head + sum tail 
```

> В данном примере, рекурсивный шаг будет выполнятся до момента пока не закончаться все элементы в tail. 

> А в самом рекурсивном шаге мы вызываем рекурсивную функцию sum и в нее передаем tail.

> В свою очередь, в стеке память складывается первый элемент (head) каждого переданого списка.

## Сопоставление c образцом (match ... with)
- **Сопоставление с образцом** - это способ проверить значение и выполнить действие, которое подходит. Аналог switch case. 
- В сопоставление передается значение для проверки (match значение with)

**Пример:**
```
match number with 
| 5 -> "Это число: 5"
| _ -> "Это число не 5"
```

**Пример:**
```
match number with 
| number when number > 5 -> "Число больше 5"
| _ -> "Число меньше 5"
```

> В данном примере, в первом условии мы говорим: Число когда число больше 5, то .. .То есть таким образом мы можем использовать условие внутри сопоставления.

## Кортеж (tuple)
- **Кортеж** - это объединение нескольких значений разного или одного типа в одну структуру. 
- Кортеж может содержать как типы данных, так и списки.
- Для обозначения кортежа используются круглые скобки и перечсление через запятую.

**Пример:**
```
let tuple = ("Daniel", 20, true, 8.2)
```
> В данном примере кортеж состоит из значений: string * int * bolean * double

**Пример:**
```
let tuplesList = 
    [
        (1, 2, 3)
        (4, 5, 6)
        (7, 8, 9)
    ]
```

> В данном примере создан список, который содержит кортеж.

> Такой список состоит из следющего типа: (int * int * int) list, то есть список который состоит из 3-х int.

**Обращение к элементу списка:**
```
let firstElement = List.item 0 numbers
```

> 0 - это индекс, а numbers - это список

**Обращение к элементу кортежа:**
```
let (name, age, _, grade) = person
```

> Мы создали для каждого значения из кортежа по перменной, которая хранит значение из кортежа согласно индексации.

> Если какое-то значение не надо сохранять в переменную, то ставим "_"

## Деструктуризация кортежа 
- **Деструктуризация** - это разбитие сложных данных на более простые. То есть извлечь несколько данных из одной структуры и сразу им присвоить пременные.

**Прмиер:**
```
let a, b, c = (1, 2, 3)
```

## Функции высшего порядка 
- **Функция высшего порядка** - это функция, которая принимает в качестве аргумента другую функцию или возвращает функцию.

**Пример:**
```
let t1 = (1, 2, 3) // Кортеж

let sum x, y, z = 
    z + y + z

let sumPlusFive = sum t1 5
```

## Обобщеные типы 'a
- **'a** - это параметр типа, который обозначает произвольный тип данных. Он позволяет функции работать с разными типами данных, не привязываясь к конкретному типу.
- Если у функции есть ограничения на тип, то передаваемые данные должны соответствовать этим ограничениям.

**Пример:**
```
let exapmpleFunction (transform: 'a -> int) (value: 'a) =
    ...
```

## Лямбда функции (fun)
- **Лямбда функция** - это функция без названия, ее можно вызывать в местах где нужно произвести какую-либо операцию без объявления отдельной функции.

**Пример:**
```
let someFunction (fun i -> i * 2) someVariable = 
    ...
```
