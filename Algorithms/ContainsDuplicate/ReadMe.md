# Contains Duplicate

## Условие

Дан массив целых чисел `nums`.

Необходимо вернуть `true`, если хотя бы одно значение встречается в массиве два или более раз. Если все элементы уникальны, вернуть `false`.

## Пример

Входные данные:

```text
nums = [1, 2, 3, 1]
```

Результат:

```text
true
```

Входные данные:
```text
nums = [1, 2, 3]
```

Результат:

```text
false
```
